# 3 · Amana — the gate, two speeds

What enters trusted memory and the direction the self takes is
owner-resolved; the machine drafts and counts, the human alone commits;
non-human origin fails closed; the gate is kept rare so it never rots into
rubber-stamp. Reversible acts inside ruled boundaries may execute now and
confirm at the next arrival — marked provisional, with a named revert path,
never entering trusted memory before the keystroke. Irreversible or outward
acts wait.
