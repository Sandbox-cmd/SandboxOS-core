# flat/ — the pair the machine cannot tell apart

every check in this suite measures a removal: a word gone, a capital gone,
a negator gone. nothing measures what is left. so a line can pass every
regex and still read like a manual.

each `row-N.fail.md` is that line, and `row-N.pass.md` is the same fact
with the workshop's character on it. `test_flat_fixtures_pass_every_regex`
asserts that **both** pass every mechanical check — that is the point. the
difference is the owner's eye, and no green run stands in for it.

eight rows of `soul/surfaces.md` are covered here, one per printed family.
the full per-row set lands with C4, when the re-voicing gives every row a
real line to sit beside.
