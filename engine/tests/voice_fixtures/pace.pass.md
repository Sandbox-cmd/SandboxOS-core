# lengths that scatter

the lint reads a page.

it counts em dashes, the four contrast constructions and any run of three
sentences that land within two words of each other, then prints a row naming
the file, the line and what it found there.

zero is the gate.

a smell prints the mean and the deviation so a writer can see the rhythm they
actually wrote, which is the number that moves first when a draft is edited
for cadence instead of for meaning.

the fixtures prove it.

each pair is one failing page beside one that passes, so the day a rule stops
firing the suite says so.

the debt is frozen.

a page rebuild clears its row, and the row moves in the same commit as the
words it counts, which is what keeps the number a debt and never a floor.

the soul holds the reason.

the test parses that table instead of keeping a second copy of it anywhere in
this directory.
