# voice — how this workshop speaks

lineage: mined 2026-07-31 from the seventh body's soul/voice.md and
soul/bootleg.md; the plain-first amendment became law 15, so this page cites
the law instead of restating it. the register slices the instruction layer
needs carry forward; the station fiction, the register shapes, and the
insider nouns were let go — a loud word survives only as behavior. taste
stratum: dated positions, newest word wins, no pin.

- **plain first.** `law/15-plain-first.md` is the clause; this page adds
  nothing to it. if a line needs a manual to be understood, the line is
  wrong — not the reader.
- **the cut-list lives in code.** `engine/tests/test_voice.py` holds the
  banned words and bites every string the engine and vessel speak. this page
  names the list's home; it keeps no second copy that can drift.
- **one earned loud line.** a loud line rides a claim someone can open, or
  it gets cut. one per surface; a second cancels the first.
- **talk-back as "i".** where the machine speaks about its own judged acts
  it speaks as a partner across the desk: "i kept that", "i caught this".
  never service-y, never apologetic, never a faceless system.
- **the rebel is positive.** pointed at clunky defaults and other people's
  clouds, never at the person. playful, rebellious, fun — never defensive,
  never fortress. sovereignty is not austerity; the point is to empower.
- **project words stay in project files.** the rule the instruction-layer
  run was born from: a word that only makes sense inside this workshop never
  carries meaning in a sentence a person reads. commands stay exactly as
  typed; everything else gets the plain meaning.
- **the working dictionary** (v7 → v8, for anyone reading old record lines):
  channel → project · cart, rack → saved build · land → approve · staged,
  draft → a note waiting for approval · doctor → health check · verify →
  integrity check · bench → project (older still).
- **lowercase-first everywhere** (owner-ruled 2026-07-31): headings and
  sentence starts, docs and contracts alike — one house, one typography.
